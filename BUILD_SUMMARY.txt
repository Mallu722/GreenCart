🚀 QUICK START INSTRUCTIONS
================================================================================

REQUIREMENT: Node.js v16+, MongoDB

WINDOWS:
  1. Open GreenCart folder
  2. Run: start.bat
  3. Wait for servers to start
  4. Open browser to: http://localhost:5173

MAC/LINUX:
  1. Open terminal in GreenCart folder
  2. Run: bash start.sh
  3. Wait for servers to start
  4. Open browser to: http://localhost:5173

MANUAL:
  Terminal 1:
    cd backend
    npm install
    npm run dev
  
  Terminal 2:
    cd frontend
    npm install
    npm run dev

THEN:
  • Frontend: http://localhost:5173
  • Backend: http://localhost:5000
